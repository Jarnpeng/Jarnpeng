Thinkb4do Theme Core v2.4.4 — Header Search Fix

สิ่งที่แก้:
- เปลี่ยนช่องค้นหาส่วนหัวให้เป็นฟอร์มค้นหาจริงของ WordPress แบบ method=get action=/ พร้อม name=s
- กด Enter แล้วค้นหาได้ แม้ JavaScript หรือ AJAX search มีปัญหา
- เพิ่มปุ่มค้นหาในช่องค้นหาส่วนหัวสำหรับเดสก์ท็อป
- เพิ่มปุ่มค้นหาในส่วนหัวสำหรับมือถือ เมื่อกดจะเปิดแผงค้นหาใต้ header
- ยังรองรับ live dropdown เดิมผ่าน #headerSearchInput และ #searchResults
- ไม่กระทบแถบล่างมือถือที่เหลือ หน้าแรก / ชุมชน / สินค้า
- ไม่กระทบการซ่อน footer และแถบล่างในหน้าชุมชน
