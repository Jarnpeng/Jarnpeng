Thinkb4do Theme v2.1.7 — Thai Legal / Policy Page Sync

สิ่งที่เพิ่ม:
1. เพิ่มกลุ่มหน้า กฎหมายและนโยบาย เข้า WordPress อัตโนมัติเมื่ออัปโหลด/เปิดใช้ธีม
2. เพิ่มเมนูหลักแบบแยกกลุ่ม: นโยบาย
3. เพิ่มหน้าแยกภายใต้กลุ่มนโยบาย:
   - นโยบายความเป็นส่วนตัว
   - นโยบายคุกกี้
   - ข้อกำหนดการใช้งาน
   - นโยบายคืนเงินและยกเลิกบริการ
   - คำขอใช้สิทธิข้อมูลส่วนบุคคล
   - ติดต่อและร้องเรียน
   - ทรัพย์สินทางปัญญา
   - ข้อมูลผู้ให้บริการและสถานะธุรกิจ
4. เพิ่มเมนู Footer ชื่อ Thinkb4do Legal และผูกเข้าตำแหน่ง Footer 2 หากยังว่าง
5. ตั้งหน้า privacy-policy เป็น WordPress Privacy Policy page อัตโนมัติ
6. เพิ่ม shortcode [thinkb4do_legal_status] สำหรับแสดงสถานะข้อมูลกฎหมาย/นโยบาย
7. เพิ่มตัวเลือกใน Customizer > ซิงก์หน้า / Components เพื่อปรับ:
   - ชื่อเว็บไซต์/ผู้ให้บริการ
   - สถานะธุรกิจ/จดทะเบียน
   - อีเมลติดต่อเรื่องนโยบาย/ข้อมูลส่วนบุคคล
   - กรอบเวลาตอบกลับคำขอ/ร้องเรียน
   - วันที่ตรวจทานนโยบายล่าสุด
8. เพิ่ม CSS รองรับ dropdown เมนู Desktop และเมนูย่อยบน Mobile

ข้อควรทราบ:
- ข้อความนโยบายเป็นโครงตัวอย่าง ไม่ใช่คำปรึกษากฎหมาย
- ควรตรวจสอบเนื้อหากับผู้เชี่ยวชาญก่อนเปิดใช้งานเชิงพาณิชย์จริง
- ระบบไม่ใช้โลโก้หรือเครื่องหมายหน่วยงานราชการก่อนมีสิทธิ์จริง

วิธีใช้งาน:
1. อัปโหลดธีม ZIP แล้ว Activate หรืออัปเดตธีม
2. ไปที่ Appearance > เชื่อมหน้า / Components
3. กด “ซิงก์หน้าและเมนูตอนนี้”
4. แก้ไขเนื้อหาหน้านโยบายได้จาก Pages / Gutenberg
5. ปรับข้อมูลกลางได้จาก Customizer > ซิงก์หน้า / Components

ตรวจสอบแล้ว:
- PHP lint: ผ่าน
- JavaScript syntax check: ผ่าน
- ZIP integrity: ผ่าน
