งานที่ปรับ:
- ปรับความกว้าง Cover / เมนูสมาชิก / พื้นที่คอนเทนต์ ให้ใช้แกนเดียวกัน
- รื้อหัวโปรไฟล์ให้เป็นมาตรฐาน: Cover ชัดขึ้น, รูปโปรไฟล์, ชื่อ, Bio, ข้อมูลสมาชิก และปุ่มจัดการอยู่ตำแหน่งชัดเจน
- เอาส่วนข้อมูลซ้ำในคอลัมน์ซ้ายออก โดยซ่อนการ์ดข้อมูลสมาชิกที่ซ้ำกับหัวโปรไฟล์
- คงเมนูสมาชิกครบ: หน้าหลัก, โพสต์, คอมเมนต์, บันทึก, ติดตาม, กลุ่ม, ตลาด, แชท, สินค้า, ตั้งค่า
- ปลดล็อกเมนู กลุ่ม / ตลาด / แชท ให้เป็นเมนูหลักของสมาชิก
- ปรับการ์ดโพสต์และ media ให้เต็มการ์ดและคลีนขึ้น
- รองรับ responsive ทั้ง desktop, tablet และ mobile

ตรวจสอบ:
- PHP lint ผ่านทุกไฟล์
- JS syntax check ผ่านทุกไฟล์
