Thinkb4do Community v4.2.205 — Premium Social UI Real System

คำอธิบายก่อนสร้างระบบ
- เป้าหมาย: ยกระดับหน้าชุมชน/ฟีด/สมาชิกให้ใกล้ reference ที่ผู้ใช้เลือก โดยทำเป็นระบบจริง ไม่ใช่ภาพตัวอย่าง
- แกนงาน Thinkb4do / Thinkb4do Community: ดึงปกวิดีโอจริง, จัดปุ่มย้อนกลับเข้าตำแหน่ง, ทำเมนูฟีดให้เห็นชัด และทำหน้าโปรไฟล์สมาชิกให้สะอาดขึ้น

ของเดิมยังอยู่ไหม
- CPT, ฟีด, Composer, Reels Viewer, Post Actions, Member Area, Comments และระบบวิดีโอเดิมยังอยู่
- ไม่ลบระบบหลัก ไม่เปลี่ยนโครง left / center / right เดิม
- เมนูล่างมือถือยังคงถูกซ่อนตามโจทย์เดิม

สิ่งใหม่ที่เพิ่มเข้าไป
1) Video Cover Real Pull
- เพิ่ม runtime JS สำหรับตรวจ iframe YouTube / YouTube-nocookie แล้วตั้ง background thumbnail อัตโนมัติ
- ใช้ลำดับ thumbnail: maxresdefault > hq720 > sddefault > hqdefault > fallback gradient
- ถ้าเป็นวิดีโออัปโหลดเอง ใช้ poster ของ video ถ้ามี

2) Back Button Position Fix
- เพิ่ม data-tb4c-smart-back-target ให้ header ของหน้าฟีดและหน้าสมาชิก
- ปรับ JS Smart Back ให้แทรกปุ่มย้อนกลับในตำแหน่ง header ไม่ลอยทับการ์ดหรือข้อมูลสมาชิก

3) Feed Menu Clarity
- เพิ่ม header: ชุมชน Thinkb4do / พื้นที่เรียนรู้ แบ่งปัน และเติบโตไปด้วยกัน
- เพิ่ม tab หลัก: วันนี้ / รีลเด่น / โพสต์ล่าสุด
- ปรับ Reels ให้เป็นการ์ดแนวนอนใหญ่ขึ้น เห็นปกและปุ่ม play ชัดขึ้น

4) Member/Profile Premium Layout
- เพิ่ม header: สมาชิก Thinkb4do
- ปรับ Hero Card สมาชิก: avatar, admin, badge, joined date, ปุ่ม + โพสต์ / โปรไฟล์ / ตั้งค่า
- ปรับ tabs เป็น รวม / โพสต์ / คอมเมนต์ / บันทึก ให้ชัดตาม reference
- ปรับ stat cards ให้ดูโปร่งและอ่านง่าย
