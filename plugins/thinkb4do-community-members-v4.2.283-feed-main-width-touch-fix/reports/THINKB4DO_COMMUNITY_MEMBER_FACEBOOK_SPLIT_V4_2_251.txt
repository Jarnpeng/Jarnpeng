Thinkb4do Community Members v4.2.251
Member Area Facebook-like Split Layout

สิ่งที่ปรับ:
- ปรับหน้า Overview ของพื้นที่สมาชิกให้เป็น 2 คอลัมน์ตามจุดสีแดงในภาพอ้างอิง
- คอลัมน์ซ้าย: ข้อมูลสมาชิกแบบ Facebook เช่น ข้อมูลสั้น บทบาท พื้นที่ วันที่เข้าร่วม ความสนใจ ช่องทางติดต่อ สรุปโปรไฟล์ และความสมบูรณ์ของโปรไฟล์
- คอลัมน์ขวา: ฟีดของสมาชิกแบบฟีดหลัก แสดงโพสต์จริงของ user เป็นแนวตั้ง อ่านง่าย ไม่ใช่กริดรก
- ย้ายสถิติที่เคยเป็นแถวยาวในหน้า Overview เข้าไปอยู่ในการ์ดข้อมูลฝั่งซ้าย เพื่อลดความรก
- หน้าอื่น ๆ เช่น โพสต์, คอมเมนต์, บันทึก, ติดตาม, ผลิตภัณฑ์, ตั้งค่า ยังใช้โครงเดิมและยังแสดงสถิติแนวนอนตามเดิม
- รองรับ responsive: desktop เป็น 2 คอลัมน์, tablet ปรับขนาดอัตโนมัติ, mobile เรียงเป็นคอลัมน์เดียว

ไฟล์ที่แก้:
- thinkb4do-community-members.php: อัปเดตเวอร์ชันเป็น 4.2.251
- templates/member-area-content.php: เพิ่มโครง 2 คอลัมน์สำหรับ Overview
- assets/member-responsive-standard.css: เพิ่ม CSS ชุด v4.2.251 สำหรับ split layout

สถานะตรวจงาน:
- PHP lint ผ่านทุกไฟล์
- โครงสร้างเดิมยังอยู่
- เพิ่มเฉพาะ layout ใหม่ของหน้า Overview
- ไม่ดึง sidebar ซ้าย/ขวาเดิมกลับมา
