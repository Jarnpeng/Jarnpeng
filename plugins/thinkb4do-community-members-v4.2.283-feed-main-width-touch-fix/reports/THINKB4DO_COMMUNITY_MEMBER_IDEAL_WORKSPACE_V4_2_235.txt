Thinkb4do Community Members v4.2.235 — Member Ideal Workspace

สิ่งที่ปรับ:
1) จัดหน้าสมาชิกใหม่ให้เป็น Member Workspace มากขึ้น
   - หัวโปรไฟล์มี Cover / Avatar / Bio / Role / Location / สถานะโปรไฟล์
   - เพิ่มแถวสรุปโปรไฟล์, โพสต์, ผู้ติดตาม บน Hero

2) เพิ่ม Overview Dashboard
   - การ์ดโปรไฟล์ของฉัน
   - แถบความครบถ้วนโปรไฟล์
   - รายการสิ่งที่ควรเติม
   - ทางลัดหลัก: สร้างโพสต์ / แก้โปรไฟล์ / สิ่งที่บันทึก
   - ขั้นต่อไปของสมาชิก

3) ปรับแท็บสมาชิกให้ถูกทางขึ้น
   - ภาพรวม
   - โพสต์
   - คอมเมนต์
   - บันทึก
   - ติดตาม
   - ตั้งค่า

4) ปรับสถิติหน้าสมาชิก
   - โพสต์ทั้งหมด
   - ความคิดเห็น
   - บันทึกไว้
   - ผู้ติดตาม
   - ยอดเข้าชม

5) ปรับ CSS แบบ scoped เฉพาะหน้าสมาชิก
   - ไม่กระทบฟีดหลัก
   - ไม่ดึง sidebar หลักมาซ้อน
   - Responsive desktop/tablet/mobile
   - ใช้สี Thinkb4do: green/white/orange/black แบบพอดี

ตรวจสอบแล้ว:
- PHP lint ผ่านทุกไฟล์
- ไม่เพิ่ม library ใหม่
- ไม่เพิ่มข้อมูล backend ให้หน้าเว็บ
- ยังใช้ shortcode [thinkb4do_member_area] เหมือนเดิม
