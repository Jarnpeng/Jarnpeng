Thinkb4do Community Members v4.2.274
เพิ่มเมนูการใช้พื้นที่การใช้งานตาม User ID

สิ่งที่เพิ่ม:
- เพิ่มแท็บ “พื้นที่” ในเมนูพื้นที่สมาชิก /member-area/?tb4c_area=usage
- แสดง User ID, พื้นที่ใช้แล้ว, quota เริ่มต้น 500 MB, พื้นที่คงเหลือ และเปอร์เซ็นต์ใช้งาน
- แยกการใช้พื้นที่เป็น รูปโปรไฟล์, Cover, ไฟล์โพสต์, ไฟล์คอมเมนต์, ไฟล์อื่น ๆ
- แสดงโฟลเดอร์ของสมาชิกตาม users/{user_id}-{slug}
- แสดงไฟล์ล่าสุดของสมาชิกที่ระบบตรวจพบ

จุดที่แก้:
- thinkb4do-community-members.php
- templates/member-area-content.php
- assets/member-responsive-standard.css

สถานะ:
- ไม่ลบของเดิม
- เพิ่มเฉพาะแท็บใหม่และ helper สำหรับคำนวณพื้นที่
- รองรับ responsive มือถือ/แท็บเล็ต/เดสก์ท็อป
