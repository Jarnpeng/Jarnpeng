Thinkb4do Community Feed Main v4.2.267

หัวข้อ: ซ่อมหน้าแสดงความคิดเห็นให้เท่าหน้าฟีดและไม่เพี้ยน

สิ่งที่แก้:
1. แยกหน้า Single/Comment ออกจาก CSS legacy ชุด IG/native/reference ที่ทำให้ลำดับ UI เพี้ยน
2. จัดลำดับหน้าแสดงความคิดเห็นใหม่ให้เหมือนการ์ดฟีด:
   - ปุ่มกลับฟีด
   - แถบผู้โพสต์ / รูปโปรไฟล์ / เวลา / สถานะ / แก้ไข-ลบ
   - หัวข้อโพสต์
   - เนื้อหาโพสต์
   - แท็ก / สื่อ / โพล
   - action row
   - ความคิดเห็น / ช่องพิมพ์ความคิดเห็น
3. คุมความกว้างหน้าแสดงความคิดเห็นและหน้าฟีดไว้ที่ 760px เท่ากัน
4. ลด class เก่าที่ทำให้ layout ถูกบังคับเป็นตำแหน่งผิด
5. เพิ่ม scope CSS เฉพาะ #tb4c-single-post-page-v4267 เพื่อไม่ทับส่วนอื่นของเว็บ
6. คงหน้าสมาชิกออกจาก Feed Main ตามโจทย์เดิม
