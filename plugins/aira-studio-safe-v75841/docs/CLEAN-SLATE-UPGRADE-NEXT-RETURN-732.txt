สิ่งที่เพิ่ม/แก้:
1. เพิ่มปุ่ม อัปเกรด ในแถวปุ่มใต้ code block เมื่อโค้ดมี <?php และ Plugin Name
2. เพิ่มปุ่ม Next ในแถวปุ่มใต้ code block เมื่อโค้ดมี <?php และ Plugin Name
3. ปุ่ม Next ยังต้องใช้ช่องพิมพ์ข้อความสั้น ๆ ก่อนกด เพื่อให้ระบบรู้ว่าจะปรับต่ออะไร
4. เมื่อกด Next ระบบส่งบริบทโค้ด เวอร์ชัน ไฟล์ และคำสั่งสั้น ๆ ให้ AiRA ทำงานต่อแบบ loop ได้
