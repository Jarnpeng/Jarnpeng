AiRA Studio v7.5.5 — Continuous Choice Composer

เป้าหมาย
- เพิ่มระบบคุยต่อเนื่องจากคำตอบฝั่งผู้ตอบ คล้าย GPT
- หากคำตอบมีเงื่อนไข/ตัวเลือก/ลำดับ เช่น 1, 2, 3 ระบบจะแสดงชิปตัวเลือกใต้คำตอบ
- ผู้ใช้สามารถกดตัวเลข หรือพิมพ์เลขใน Composer เพื่อคุยต่อจากบริบทเดิมได้

ของเดิมยังอยู่
- Code block, Copy, Download, Preview, Debug สด, สร้างระบบ, Package, Install และ Upgrade flow ยังอยู่ครบ
- ไม่ลบ UI/UX เดิมและไม่เพิ่มปุ่มซ้ำใต้ code block
- Composer ยังคงยึดส่วนล่างตามระบบเดิม

สิ่งที่เพิ่ม
1. ปุ่ม Answer ฝั่งผู้ตอบ
   - กดแล้ว Composer จะใส่คำว่า Answer
   - มี hidden continuation prompt เพื่อส่งบริบทคำตอบเดิมให้ AiRA คุยต่อโดยไม่เริ่มใหม่

2. Choice chips ใต้คำตอบ
   - ตรวจจับรายการแบบ 1. / 1) / 1: / ข้อ 1 / เลขไทย ๑ ๒ ๓ และ A-H
   - แสดงชิปตัวเลข + ข้อความย่อ
   - กดชิปแล้ว Composer จะแสดงเลข/ตัวเลือกที่เลือก เช่น เลือกข้อ 1: ...
   - เมื่อกดส่ง ระบบจะส่ง prompt ภายในที่มีบริบทคำตอบเดิมแนบไปด้วย

3. Typed number continuation
   - หากผู้ใช้พิมพ์เฉพาะ 1, 2, 3 หรือ “ข้อ 1” ใน Composer หลังคำตอบที่มีตัวเลือก
   - ระบบจะจับคู่กับตัวเลือกในคำตอบล่าสุดโดยอัตโนมัติ
   - ช่วยคุยต่อจากตัวเลือกนั้นทันที

วิธีใช้
1. ให้ AiRA ตอบคำถามที่มีตัวเลือก/ลำดับ
2. ดูใต้คำตอบฝั่งผู้ตอบ จะเห็น “คุยต่อด้วยตัวเลข”
3. กดตัวเลขที่ต้องการ หรือพิมพ์ 1 / 2 / 3 ใน Composer
4. กดส่ง เพื่อคุยต่อจากตัวเลือกนั้น

ตรวจบั๊ก
- PHP lint: ผ่าน
- JS syntax check: ผ่าน
- ZIP integrity: ผ่านหลังแพ็ก
- จุดที่ต้องทดสอบจริงใน WordPress: การกดชิปตัวเลือก, กด Answer, พิมพ์เลขเอง, และการคุยต่อผ่าน API จริง

ไฟล์/สถานะ
- assets/js/aira-studio-clean-slate.js: เพิ่ม continuation choice engine และ action handlers
- assets/css/aira-studio-clean-slate.css: เพิ่มสไตล์ชิปตัวเลือกและปุ่ม Answer
- aira-studio.php: อัปเดตเวอร์ชันเป็น 7.5.5-continuous-choice-composer

สถานะ
- พร้อมติดตั้งทดสอบใน WordPress
- ระบบนี้เป็น client-side continuation layer: ไม่เขียนฐานข้อมูลใหม่และไม่ลบของเดิม
