AiRA Studio v7.3.3 Clean Slate Force Upgrade Next Visible

แก้ปัญหาปุ่มอัปเกรด / Next ไม่ขึ้นจริงใน UI:
- บังคับแสดงปุ่ม อัปเกรด และ Next ใต้ code block ทุกก้อน
- Next Loop แสดงช่องพิมพ์สั้น ๆ ทุก code block เพื่อให้กดปรับต่อได้เรื่อย ๆ
- ถ้า code block เป็น WordPress Plugin ที่ติดตั้งได้ ปุ่มอัปเกรดจะใช้ระบบอัปเกรดปลั๊กอินเดิม
- ถ้ายังไม่ใช่ปลั๊กอิน WordPress เต็มรูปแบบ ปุ่มอัปเกรดจะส่งคำสั่งเข้าแชทให้ AiRA อัปเกรดโค้ดและตอบกลับเป็น code block ใหม่แทน ไม่เขียนไฟล์มั่ว
- เพิ่ม CSS force visibility เพื่อกันเงื่อนไข/สไตล์เก่าซ่อนปุ่ม
