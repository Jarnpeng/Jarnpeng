สิ่งที่เพิ่ม:
1. Assistant Slide Answer Cadence
   - ปรับการสไลด์ตัวอักษรคำตอบให้มีจังหวะคิดมากขึ้น
   - เพิ่ม pause หลังเครื่องหมายวรรคตอน, ขึ้นบรรทัดใหม่, paragraph และ code fence
   - ลด chunk สั้นลงเพื่อให้เหมือนการพิมพ์/stream คำตอบมากขึ้น

2. Continuous Reading Processor
   - ระหว่างรอ API ระบบจะสลับข้อความอ่านข้อมูลไปเรื่อย ๆ จนกว่าจะได้คำตอบจริง
   - แสดงสถานะอ่านคำถาม, เชื่อมบริบท, ตรวจตัวเลือก 1 2 3, ตรวจ code/system flow และเรียบเรียงคำตอบ
   - มีจุดสามจุดนุ่ม ๆ ทั้งใน processor และแถบ processing

3. Runtime Safety
   - เมื่อได้คำตอบจริง processor loop จะหยุดทันที
   - เมื่อลบ processor หรือเกิด error จะ clear timer ป้องกัน loop ค้าง
