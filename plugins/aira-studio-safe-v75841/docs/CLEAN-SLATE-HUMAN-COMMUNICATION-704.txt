AiRA Studio v7.0.4 — Clean Slate Human Communication Tools

สิ่งที่เพิ่ม:
1) เพิ่มไอคอนแก้ไขข้อความฝั่งผู้ถาม
   - ผู้ถามสามารถกดแก้ไขข้อความของตนเองในประวัติแชทได้
   - บันทึกลง room/local sync เหมือนข้อความเดิม
   - ไม่ดึง UI legacy กลับมา จึงยังรักษา clean shell เดิม

2) รักษาเครื่องมือฝั่งผู้ตอบจาก v7.0.3
   - คัดลอก
   - Show more / Show less
   - เล่นเสียงแบบ inline player ดันพื้นที่ลงใต้คำตอบ
   - แก้ไขข้อความผู้ตอบ

3) เพิ่ม Human Communication Guide
   - ก่อนส่งไปยัง API จะมี instruction wrapper แบบ privacy-safe
   - เป้าหมายคือให้คำตอบเข้าใจง่าย ใช้ได้กับหลายอาชีพ เพศ วัย อายุ และพื้นฐานความรู้
   - ไม่เดา ไม่เหมารวม และไม่เก็บข้อมูลอ่อนไหวอัตโนมัติ
   - ปรับภาษาจากบริบทที่ผู้ใช้ระบุเองเท่านั้น

สถานะโครง UI:
- Header ชิดใต้ WordPress admin bar
- Composer ชิดล่าง
- ChatLog เป็น scroll หลักตัวเดียว
- CSS หลัก 1 ไฟล์
- JS หลัก 1 ไฟล์
