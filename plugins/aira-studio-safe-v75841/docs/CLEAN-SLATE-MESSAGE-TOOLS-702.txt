AiRA Studio v7.0.2 Clean Slate Message Tools

เป้าหมาย:
- เอาไอคอนเครื่องมือบนข้อความกลับมา โดยไม่ดึง UI legacy ที่ทำให้ซ้อนกลับมา
- คง Clean Slate shell: Header / Chat Log / Bottom Composer

สิ่งที่เพิ่มกลับ:
1. ผู้ถาม: ปุ่มคัดลอกข้อความ
2. ผู้ตอบ: ปุ่มคัดลอกข้อความ
3. ผู้ตอบ: Show more / Show less สำหรับคำตอบยาว
4. ผู้ตอบ: ปุ่มเล่นเสียงเฉพาะข้อความนั้น ใช้ TTS AJAX ถ้ามี และ fallback เป็น browser speech synthesis
5. ผู้ตอบ: ปุ่มแก้ไขข้อความแบบ inline พร้อมบันทึก/ยกเลิก และ sync เข้าห้องปัจจุบัน

หลักการป้องกันซ้อน:
- ไม่เพิ่ม legacy panel กลับมา
- ไม่เปลี่ยน data-action เดิมของเมนูหลัก
- เพิ่มเฉพาะ message tools ภายใน .aira-message
- CSS/JS active ยังเป็นไฟล์หลักอย่างละ 1 ไฟล์

ทดสอบที่ควรทำ:
- ส่งข้อความผู้ถาม แล้วกดคัดลอก
- ให้ AiRA ตอบข้อความยาว แล้วกด Show more / Show less
- กดเล่นเสียงผู้ตอบ
- กดแก้ไขข้อความผู้ตอบ แล้วบันทึก/ยกเลิก
- เปิดบน mobile เพื่อเช็กว่าไอคอนไม่กินพื้นที่ composer
