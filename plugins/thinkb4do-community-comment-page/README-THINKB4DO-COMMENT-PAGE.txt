Thinkb4do Community Comment Page v1.0.19

อัปเดต v1.0.19
- แก้อาการไอคอนแก้ไข/ลบเห็นแวบเดียวแล้วโดนชั้นอื่นบัง
- ย้ายไอคอนแก้ไข/ลบออกจากกล่องข้อความ ไปเป็นคอลัมน์ขวาแยกของแต่ละความคิดเห็น
- เอา class ปุ่มเจ้าของชุดเก่าที่ซ้ำ/เสี่ยงโดน CSS ทับออก แล้วใช้ class ใหม่ชุดเดียว
- คงเงื่อนไข: คอมเมนต์หลักมีคัดลอก+ตอบกลับ, คอมเมนต์ย่อยไม่มีตอบกลับ, เจ้าของคอมเมนต์มีแก้ไข/ลบด้านขวา


ปลั๊กอินนี้ใช้แยกหน้าแสดงความคิดเห็นของโพสต์ชุมชนออกจาก Feed Main
เหมาะสำหรับหน้า single post ของ post type: tb4_community_post

อัปเดต v1.0.3
- คืนไอคอนมาตรฐานของปุ่ม ตอบกลับ / แก้ไข / ลบ / คัดลอก ให้ใช้ SVG ในตัว ไม่พึ่ง icon font ภายนอก
- แก้กรณีไอคอนหายเพราะไฟล์ icon ภายนอกโหลดไม่ทันหรือถูก cache ทับ
- เพิ่มคำสั่งกด Enter เพื่อส่งความคิดเห็นทันที
- กด Shift + Enter เพื่อขึ้นบรรทัดใหม่ได้ตามปกติ
- คงระบบจุด 3 จุดนุ่มระหว่างกำลังส่ง และกันกดส่งซ้ำไว้เหมือนเดิม

อัปเดต v1.0.1
- จัด UI/UX ส่วนความคิดเห็นให้สวยและเรียบร้อยขึ้น คล้ายการ์ดโพสต์ด้านบน
- แก้ปัญหาระบบซ้อนกับสคริปต์ฟีดหลัก โดยแยก data attribute ของหน้า comment page
- เพิ่มระบบกันส่งซ้ำ / กัน comment ซ้ำ
- ปุ่มส่งความคิดเห็นแสดงจุด 3 จุดแบบนุ่มระหว่างกำลังส่ง
- ความคิดเห็นใหม่แสดงด้านบนของรายการทันทีหลังส่งสำเร็จ

วิธีติดตั้ง
1) ไปที่ WordPress Admin > Plugins > Add New > Upload Plugin
2) อัปโหลดไฟล์ ZIP นี้
3) Activate ปลั๊กอิน
4) เปิดหน้าโพสต์ชุมชน เช่น /community-post/โพสต์ใหม่/
5) ทดสอบพิมพ์ความคิดเห็นแล้วกด Enter เพื่อส่ง หรือกด Shift + Enter เพื่อขึ้นบรรทัดใหม่

หมายเหตุ
- ต้องใช้ร่วมกับระบบที่มี post type tb4_community_post อยู่แล้ว
- หากยังเห็น UI เก่า ให้ล้าง cache ของเว็บ/เบราว์เซอร์ก่อนทดสอบ
