แก้ไขตามจุดที่ผู้ใช้วงแดง:
- ปุ่มแก้ไข/ลบของ User แสดงความคิดเห็นอยู่ด้านขวาของกล่องคอมเมนต์
- ปุ่มคัดลอก + ตอบกลับอยู่แถวล่างของคอมเมนต์
- ลบปุ่ม/ไอคอนซ้ำจากเวอร์ชันก่อนหน้า
- เปลี่ยนไอคอนเป็น inline SVG ชุดเดียว class tb4ccp-action-icon เพื่อไม่โดน CSS เก่าซ่อน
- เพิ่ม JS normalize ลบ icon fallback เก่าและปุ่มซ้ำหลัง AJAX / MutationObserver
