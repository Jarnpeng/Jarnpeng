Thinkb4do Community Comment Page v1.0.1
สถานะ: ปรับปรุงหน้าแสดงความคิดเห็นตามภาพอ้างอิง + กันระบบซ้อน + เพิ่มสถานะปุ่มส่ง 3 จุด

สิ่งที่แก้ไขแล้ว
1) UI/UX ส่วนความคิดเห็น
- ปรับกล่องความคิดเห็นให้ดูสะอาดขึ้น คล้ายการ์ดด้านบนของโพสต์
- จัด avatar / ชื่อผู้แสดงความคิดเห็น / เวลา / ข้อความ / ปุ่มแก้ไข-ลบ ให้อยู่ตำแหน่งมาตรฐาน
- ลดอาการปุ่มแก้ไข/ลบทับข้อความ โดยเพิ่ม class has-owner-tools และ padding เฉพาะรายการที่มีปุ่มเจ้าของ
- ปรับระยะห่าง รายการตอบกลับ เส้นเชื่อม reply และ animation ตอนความคิดเห็นใหม่ขึ้น

2) แก้ระบบซ้อน
- เปลี่ยน attribute ฝั่งหน้าแสดงความคิดเห็นจาก data-tb4c-comment-* เป็น data-tb4ccp-comment-* เฉพาะหน้า comment page เพื่อไม่ชนกับสคริปต์ฟีดหลัก
- เพิ่ม stopImmediatePropagation ใน submit/click handler ของปลั๊กอินนี้
- เพิ่ม form lock data-tb4ccp-submitting เพื่อกันกดส่งซ้ำและกัน AJAX ซ้ำ
- เพิ่มระบบ dedupe ลบ comment item ที่มี data-comment-id ซ้ำหลังโหลดและหลังส่งสำเร็จ

3) ปุ่มส่งความคิดเห็น
- เมื่อกำลังส่ง ปุ่มส่งจะเปลี่ยนจากลูกศรเป็นจุด 3 จุดแบบนุ่ม
- มี aria-busy และสถานะกำลังส่ง เพื่อให้ปุ่มสื่อสารกับผู้ใช้ดีขึ้น
- เมื่อส่งเสร็จ ปุ่มกลับเป็นปกติและแสดงความคิดเห็นใหม่ด้านบนของรายการความคิดเห็นทันที
