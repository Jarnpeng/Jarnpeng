แก้ตามจุดที่ผู้ใช้วงแดง:
- แถวคอมเมนต์ของ User มีปุ่มแก้ไข/ลบด้านขวาในกล่องคอมเมนต์
- แถวล่างคอมเมนต์มี คัดลอก และ ตอบกลับ อยู่ข้างกัน
- ใช้ visible real icon class ใหม่ tb4ccp-real-icon ไม่พึ่ง SVG/mask/Dashicons เพื่อกันไอคอนกลายเป็นเส้นเล็ก
- เพิ่ม footer rescue CSS/JS เพื่อกู้ปุ่มตอบกลับให้กับคอมเมนต์ที่ถูกโหลดผ่าน AJAX หรือ HTML เก่า
- คง Enter ส่ง, Shift+Enter ขึ้นบรรทัดใหม่, ปุ่มส่งแบบจุด 3 จุด, และระบบเลื่อนผ่านภาพ
