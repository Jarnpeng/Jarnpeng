Thinkb4do Community Comment Page v1.0.15

แก้ตามคำสั่งล่าสุด:
1) เอาส่วน action ที่ซ้ำออกจาก renderer/inline rescue ล่าสุด ให้เหลือกติกาเดียว
2) เจ้าของคอมเมนต์ทุกระดับ: แสดงไอคอนแก้ไข/ไอคอนลบด้านขวา
3) คอมเมนต์หลัก: แถวล่างแสดงคัดลอก + ตอบกลับครั้งแรกเท่านั้น
4) คอมเมนต์ย่อย: ไม่มีปุ่มตอบกลับ แต่ยังมีแก้ไข/ลบด้านขวาเมื่อเป็นเจ้าของหรือมีสิทธิ์
5) เปลี่ยนไอคอน action เป็น SVG ชุดเดียว ลดปัญหา glyph/font/label ซ้ำ
6) เพิ่ม JS normalizeCommentActions เพื่อเคลียร์ปุ่มซ้ำหลังโหลด AJAX/DOM update

สถานะ: ผ่าน PHP syntax check และแพ็ก ZIP พร้อมติดตั้ง
