Thinkb4do Community Comment Page v1.0.6

ทวนโจทย์:
- ให้ส่วน แสดงความคิดเห็น / ตอบกลับ / ไอคอนแก้ไข/ลบ กลับมาเป็นแบบมาตรฐาน
- ต้องไม่ทำให้ระบบเดิมที่แก้ไว้ เช่น Enter ส่ง, จุด 3 จุด, และเลื่อนผ่านภาพ เสียหาย

สิ่งที่แก้:
1) เพิ่มชั้น CSS icon recovery สำหรับความคิดเห็นโดยเฉพาะ
- ใช้ CSS mask icon ในตัวปลั๊กอิน
- ไม่ต้องพึ่ง icon font จากภายนอก
- ลดปัญหาไอคอนโดน CSS ของธีมหรือปลั๊กอินอื่นทับ

2) คืนชุดไอคอนมาตรฐาน
- แสดงความคิดเห็น / หัวข้อความคิดเห็น
- ตอบกลับ
- คัดลอกลิงก์ความคิดเห็น
- แก้ไขความคิดเห็น
- ลบความคิดเห็น
- ปุ่มส่งความคิดเห็น
- ปุ่มยกเลิกการตอบกลับ

3) จัดปุ่มแก้ไข/ลบกลับตำแหน่งมาตรฐาน
- แก้ไขสีเขียว
- ลบสีแดง
- ขนาดปุ่มเท่ากัน
- อยู่มุมขวาบนของกล่องความคิดเห็น
- เพิ่มพื้นที่ด้านขวาของข้อความเพื่อไม่ให้ซ้อนกับชื่อ/เวลา/ข้อความ

4) คงระบบเดิม
- Enter ส่งความคิดเห็น
- Shift + Enter ขึ้นบรรทัดใหม่
- จุด 3 จุดตอนกำลังส่ง
- แตะสั้นที่ภาพเพื่อเปิดรูป
- ลากบนภาพเพื่อ scroll หน้าได้

ผลตรวจ:
- PHP lint ผ่าน
- Template lint ผ่าน
- JS syntax ผ่าน
- ZIP พร้อมติดตั้งเป็นปลั๊กอิน WordPress
