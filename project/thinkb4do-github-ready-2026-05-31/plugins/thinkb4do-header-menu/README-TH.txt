# Thinkb4do Header Menu Plugin

เวอร์ชัน 1.0.15 — Mobile Profile Avatar เวอร์ชัน 1.0.8 — Mobile Profile/Icon Fix Green Search Focus Fix

ปลั๊กอินนี้แยก Header/Menu ของ Thinkb4do ออกจากธีม เพื่อให้เปิด–ปิดและอัปเดต Header ได้แยกจาก Body Layout และ Footer

## สิ่งที่ปรับในเวอร์ชันนี้
1. ตกแต่ง Header ให้เบาขึ้นด้วยแนว Minimal Glass / Soft UI
2. จัดกลุ่มไอคอนด้านขวาให้ดูสะอาด ลดความรก และยังใช้งานได้เหมือนเดิม
3. ปรับปุ่มเมนู 9 ช่องให้เด่นขึ้นแบบพอดี ไม่หนักสายตา
4. ปรับช่องค้นหา เมนูหลัก ปุ่มเข้าสู่ระบบ และ avatar ให้สมดุลขึ้น
5. ปรับ Popup เมนู / แจ้งเตือน / ข้อความ / ค้นหา ให้เบาและอ่านง่ายขึ้น
6. เพิ่มการรองรับ Responsive สำหรับ Desktop / Tablet / Mobile
7. ลดเงาหนักและลดความเสี่ยง CSS ไปกระทบส่วนอื่นของเว็บ โดย scope สไตล์ให้ชัดขึ้น
8. รองรับ prefers-reduced-motion สำหรับผู้ใช้ที่ไม่ต้องการ animation
9. เอาชื่อผู้ใช้/คำว่า “สมาชิก” ออกจาก Header ด้านขวา เหลือเฉพาะรูปโปรไฟล์เพื่อให้แถบหัวเว็บเบาขึ้น
10. ปรับคำว่า “ค้นหา” ให้ไปอยู่ในช่องค้นหา และเปลี่ยนปุ่มส่งค้นหาเป็นไอคอนเล็กเพื่อลดความรก

## วิธีติดตั้ง
1. ไปที่ WordPress Admin > Plugins > Add New > Upload Plugin
2. อัปโหลดไฟล์ ZIP เวอร์ชันนี้
3. Activate Plugin หรือ Replace เวอร์ชันเดิม
4. ล้าง cache ของเว็บ / browser หากยังเห็นหน้าตาเดิม

## โครงที่แยกแล้ว
- Header/Menu: ปลั๊กอินนี้ควบคุม
- Body Layout: อยู่ในธีมเดิม
- Footer: อยู่ในธีมเดิม

## สถานะ
เชื่อมต่อผ่านฟังก์ชัน `tb4_header_menu_render()` และมี fallback ในธีมหากปิดปลั๊กอิน
