ปลั๊กอินแยก Sidebar ซ้ายสำหรับ Community เฉพาะ Desktop แบบ Native Blend เมนูหลักเหลือเฉพาะ ฟีดชุมชน / สมาชิก และเพิ่มส่วน Recents ที่ดึงตาม user ID ของสมาชิกที่ล็อกอิน มีสกรอลล์หลังหัวข้อที่ 10 และมีนโยบายพร้อมลิงก์สำคัญของเว็บไว้ส่วนล่าง ไม่ยาวเกินโซนนโยบาย

== Features ==
- วาง Sidebar ใต้ส่วนหัวและแถบเขียว
- เมนูหลักเหลือเฉพาะ ฟีดชุมชน และ สมาชิก ตามคำสั่งล่าสุด
- เมนูหลักยังแก้ลิงก์เองได้ในหลังบ้าน
- เมนูหลักรองรับ auto:community และ auto:members เพื่อเชื่อมหน้าจริงในเว็บอัตโนมัติ
- เปลี่ยนหัวข้อส่วนโพสต์เป็น Recents
- Recents ดึงเฉพาะโพสต์ที่ผูกกับ user ID ของสมาชิกที่ล็อกอิน ไม่ดึงโพสต์สมาชิกคนอื่นมาปน
- เพิ่ม Auto Detect สำหรับ custom post type ของระบบชุมชน เพื่อแก้อาการโพสต์แล้วหัวข้อไม่ขึ้น
- รองรับระบบที่เก็บเจ้าของโพสต์ใน post_author หรือ post meta เช่น user_id, _user_id, author_id, _author_id, tcb4d_user_id, thinkb4do_user_id
- AiRA ช่วยตั้งหัวข้อสั้น ๆ จากชื่อโพสต์/คำโปรย/เนื้อหาโพสต์
- สามารถแก้ชื่อ Recents ได้ในกล่อง AiRA Recents บนหน้าแก้ไขโพสต์
- สามารถซ่อน/ลบหัวข้อออกจาก Recents ได้โดยไม่ลบโพสต์
- ถ้าลบโพสต์จริงหรือย้ายถังขยะ หัวข้อ Recents จะหายตามโพสต์
- ปุ่มแก้ไข/ลบแบบเล็กจะแสดงเมื่อชี้ที่หัวข้อ Recents สำหรับผู้มีสิทธิ์แก้ไข/ลบโพสต์
- Badge แจ้งเตือนการสนทนายังแสดงด้านขวา โดยอ้างอิงจำนวนคอมเมนต์ของโพสต์
- เพิ่มส่วนล่างเป็นนโยบาย แก้ข้อความและลิงก์สำคัญของเว็บได้จากหลังบ้าน
- ส่วนล่างเป็นแบบโปร่งใส ไม่มีกล่องพื้นหลัง ไม่แย่งพื้นที่ Recents
- รายการ Recents แสดงประมาณ 10 หัวข้อก่อน แล้วหัวข้อที่เกินให้เลื่อนด้วยสกรอลล์ภายใน ไม่ยาวทับหรือเกินส่วนนโยบาย
- Open/Close bar เป็นไอคอนโปร่งใส ไม่มีพื้นหลังแข็ง ไม่มีเงา และกลมกลืนกับเมนู
- พับแล้วเหลือเฉพาะไอคอน และจำสถานะล่าสุดด้วย localStorage
- เอาหัว Sidebar ที่มีโลโก้ T + ชื่อออกจากหน้าเว็บ
- เอา Footer ด้านล่าง “Settings | โดย Thinkb4do | ดูรายละเอียด” ออกจากหน้าเว็บ
- เมนูโปร่งใส ไม่มีกล่อง ไม่เงา ไม่แย่งความเด่นจาก Feed กลาง
- ใช้ line icons แบบสะอาด แทน emoji เมื่อใช้ icon token
- มี active state ตาม URL ปัจจุบัน
- แสดงเฉพาะ Desktop เท่านั้น
- ระบบหลังบ้านเลือกหน้า/URL ที่ต้องการให้ Sidebar แสดง
- Shortcode: [thinkb4do_community_left_sidebar]

== Installation ==
1. Upload ZIP ผ่าน WordPress Admin > Plugins > Add New > Upload Plugin
2. เลือก Replace/Update current plugin ถ้ามีตัวเดิมอยู่
3. Activate plugin
4. ไปที่ Settings > Community Left Sidebar
5. ตรวจเมนูหลัก, Recents, Badge แจ้งเตือน, ส่วนล่างนโยบาย, Open/Close bar
6. บันทึกการตั้งค่า แล้วล้าง cache หน้าเว็บ

== Menu auto links ==
ค่าเริ่มต้นเหลือ 2 รายการ:
- ฟีดชุมชน|auto:community|home
- สมาชิก|auto:members|users

ระบบจะพยายามหาเพจจริงจาก slug/title เช่น community, chumchon, ชุมชน, members, สมาชิก ก่อน หากหาไม่เจอจะ fallback เป็น /community/ และ /members/

== Recents ==
Recents ใช้ข้อมูลจากโพสต์ที่ผูกกับ user ID ของสมาชิกที่ล็อกอินเพื่อสร้างหัวข้อสั้น ๆ และเชื่อมกลับไปยังโพสต์จริง ระบบจะไม่ fallback ไปดึงโพสต์ของสมาชิกคนอื่น หากต้องการแก้ชื่อหัวข้อ ให้เปิดหน้าแก้ไขโพสต์ แล้วใช้กล่อง AiRA Recents ด้านข้าง หากต้องการซ่อนหัวข้อจาก Recents โดยไม่ลบโพสต์ ให้ติ๊ก “ซ่อน/ลบออกจาก Recents แต่ไม่ลบโพสต์”

== Lower Policy ==
ส่วนล่างของ Sidebar จะแสดง “นโยบาย” เป็นค่าเริ่มต้น สามารถเปิด/ปิด แก้หัวข้อ แก้ข้อความ และเพิ่มลิงก์สำคัญของเว็บได้ที่ Settings > Community Left Sidebar โดยใช้รูปแบบ ชื่อลิงก์|URL หนึ่งรายการต่อหนึ่งบรรทัด ค่าเริ่มต้นคือ นโยบาย / เงื่อนไข / ติดต่อ
