แก้ตามตำแหน่งจริงของแถวคอมเมนต์:
1) ปุ่มตอบกลับแสดงเฉพาะคอมเมนต์หลักชั้นแรก (depth-0)
2) ความคิดเห็นย่อยไม่แสดงปุ่มตอบกลับ
3) คัดลอกซ้ำถูกล้างออกด้วย PHP + JS normalize
4) ปุ่มแก้ไข/ลบด้านขวาของคอมเมนต์มองเห็นชัดขึ้นด้วย glyph + label สีเขียว/แดง
5) AJAX reply render เป็น depth-1 เพื่อไม่ให้ปุ่มตอบกลับโผล่ในรายการย่อย

ตรวจสอบ: PHP lint / JS syntax / CSS braces / ZIP integrity
