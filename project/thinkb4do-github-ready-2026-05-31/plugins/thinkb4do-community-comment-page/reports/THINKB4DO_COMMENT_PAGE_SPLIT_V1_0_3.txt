Thinkb4do Community Comment Page v1.0.3

สิ่งที่แก้:
- กู้ระบบคลิกภาพทุกภาพบนหน้าแสดงความคิดเห็น
- เพิ่ม lightbox ในปลั๊กอินนี้โดยตรง ลดการพึ่งพาสคริปต์ฟีดหลัก
- รองรับภาพเด่นของโพสต์ ภาพอัลบั้ม และภาพแนบในความคิดเห็น
- ปิดด้วยปุ่ม X, คลิกพื้นหลัง หรือกด Esc
- คงปุ่มตอบกลับ/แก้ไข/ลบ SVG และ Enter ส่งความคิดเห็นจาก v1.0.2

- ตั้ง lightbox ให้เป็นพื้นหลังสีดำเต็มจอจริง ไม่ใช่พื้นโปร่ง/เขียวเข้ม
