แก้ไขล่าสุด:
- ตัด CSS action rescue ซ้ำหลายเวอร์ชันออกจากท้ายไฟล์
- เอา inline footer rescue style/script ออก เพื่อลดการบังกันเองหลังโหลดหน้า
- เปลี่ยนไอคอนแก้ไข/ลบของเจ้าของคอมเมนต์เป็น icon-only พร้อมข้อความสำหรับ screen reader
- จัดปุ่มแก้ไข/ลบให้อยู่ใน flow ด้านขวาของ topline ไม่ใช้ absolute overlay
- คงเงื่อนไข: คอมเมนต์หลักมีคัดลอก+ตอบกลับ, คอมเมนต์ย่อยไม่มีตอบกลับ, เจ้าของทุกระดับมีแก้ไข/ลบด้านขวา
