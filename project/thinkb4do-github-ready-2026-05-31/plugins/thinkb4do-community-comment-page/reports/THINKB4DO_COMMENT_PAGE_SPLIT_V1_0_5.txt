Thinkb4do Community Comment Page v1.0.5

ทวนโจทย์:
- คืนปุ่มตอบกลับและไอคอนแก้ไข/ลบให้กลับเป็นแบบมาตรฐาน
- แก้ปัญหาแตะโดนภาพแล้ว scroll หน้าไม่ได้

สิ่งที่แก้:
1) คืน path SVG มาตรฐานของ reply/copy/edit/delete และใส่ CSS override ให้ขนาดคงที่
2) ปรับระบบจับ gesture ของภาพใหม่: แตะสั้น = เปิดรูป, ลาก = ปล่อยให้หน้า scroll
3) ลด threshold การตรวจจับการลากจาก 10px เหลือ 4px และกัน click หลังลาก 1.1 วินาที
4) เพิ่ม passive touch listener เพื่อลดโอกาสบล็อกการ scroll บนมือถือ
5) ตั้ง draggable=false ให้รูป/วิดีโอในโพสต์และความคิดเห็น

สถานะ: พร้อมทดสอบบนเว็บจริงหลังติดตั้งและล้าง cache
