Thinkb4do Products v2.2.0 — App Store / Payment / Email Delivery Bridge

สิ่งที่เพิ่มในเวอร์ชันนี้
- เพิ่ม Thinkb4do App Store สำหรับหน้า member-area ผ่าน shortcode [thinkb4do_app_store]
- เพิ่มเมนูผลิตภัณฑ์/แอพในพื้นที่สมาชิกเมื่อใช้งานร่วมกับ Thinkb4do Community
- คลิกแอพแล้วเปิดหน้าต่างการทำงานแบบ Mac-like: Dock, App Window, Live App Area
- เพิ่มระบบตั้งค่าสินค้าเป็นแอพ: เปิดเป็นแอพ, รูปแบบเปิดใช้งาน, ลิงก์แอพ, Shortcode, สถานะติดตั้ง
- เพิ่ม Payment Bridge: เปิดชำระเงิน, เลือก provider, Checkout URL / Payment Link
- เพิ่มระบบส่งบิล/ใบสรุปรายการทางอีเมลให้ผู้ใช้และทีมงาน
- เพิ่ม Delivery Bridge: ส่งไฟล์ทางอีเมล, ติดตั้ง/เปิดใช้งานทันที, หรือล็อกไฟล์จนกว่าจะยืนยันการชำระเงิน
- เพิ่ม App Orders สำหรับเก็บรายการสั่งซื้อ/เปิดใช้งาน
- ยังรักษาระบบเดิม: Product Portal, Detail, Affiliate, Booking, Compare, Wishlist, Locked Icon CTA, Mobile Premium Controls และ Team Settings Center

คำแนะนำติดตั้ง
1. ติดตั้ง/อัปโหลดทับ Thinkb4do Products เดิม
2. ล้าง cache/asset cache
3. แก้ไขสินค้า แล้วเปิด “เปิดเป็นแอพในพื้นที่สมาชิก”
4. ตั้งค่า Checkout URL หากต้องการชำระเงิน
5. เปิด “ส่งบิล/ใบสรุปรายการทางอีเมล” หากต้องการให้ระบบส่งอีเมลเมื่อผู้ใช้กดซื้อ/เปิดใช้งาน
6. ถ้าต้องการส่งไฟล์ ให้ใส่ “ลิงก์ไฟล์/แพ็กสำหรับส่งทางอีเมล” และเลือก delivery mode
7. ใช้ shortcode [thinkb4do_app_store] บนหน้าที่ต้องการ หรือใช้งานร่วมกับ Thinkb4do Community v4.2.96 ขึ้นไป

สถานะระบบ
- ใช้งานได้แล้วในระดับ Payment/Delivery Bridge
- การตัดเงินจริงให้ใช้ Checkout URL จากผู้ให้บริการภายนอกก่อน เช่น Stripe, PayPal, WooCommerce, Payment Link หรือช่องทางที่ทีมงานเลือก
- ระบบส่งไฟล์อัตโนมัติจะส่งเฉพาะกรณีที่ไม่ล็อกไฟล์หลังชำระเงิน
- หากล็อกไฟล์ ทีมงานต้องยืนยันการชำระเงินก่อนส่งมอบไฟล์จริง
