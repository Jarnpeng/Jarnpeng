สิ่งที่ปรับ:

4. ซ่อนส่วนซ้ำ/รก: stats บนหัวฟีด, search ซ้ำ, post context tags, reaction summary, view chip, reel action ซ้ำ, follow button บนการ์ด
5. ย่อ Composer, Reels และ Post Card ให้ compact ขึ้นโดยไม่ย้ายตำแหน่ง
6. ปรับ mobile ให้คงลำดับเดิมแต่ลดความแน่นของปุ่มและการ์ด
