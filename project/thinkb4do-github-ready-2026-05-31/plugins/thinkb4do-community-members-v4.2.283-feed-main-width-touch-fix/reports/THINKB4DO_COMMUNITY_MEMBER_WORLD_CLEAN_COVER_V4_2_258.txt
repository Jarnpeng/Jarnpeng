Thinkb4do Community Members v4.2.258

งานที่ทำ:
- รื้อเลเยอร์หน้าสมาชิกให้คลีนขึ้นในแนวแบรนด์ระดับโลก
- ทำ Cover ให้ชัดขึ้น: ลด overlay สีเขียว, เพิ่มความสูง cover, แสดงภาพด้วย background-size: cover และ position center
- ปรับ Hero ให้เรียบขึ้น: avatar, ชื่อ, ปุ่มแก้โปรไฟล์/สร้างโพสต์ อยู่ในแกนเดียวกัน
- ปรับเมนูสมาชิกให้เป็นแถบ navigation ชัดเจน ไม่เหมือนแถวสถิติ
- ลบ/ซ่อนส่วนซ้ำและส่วนรบกวนรอบหัวโปรไฟล์/ฟีด
- ปรับการ์ดโพสต์ข้อความและ Poll ให้เรียบ คลีน และใกล้ฟีดหลักมากขึ้น
- ปรับแต่ละหน้าให้มี accent/เอกลักษณ์แยกตามแท็บ แต่ยังอยู่ในระบบภาพรวม Thinkb4do เดียวกัน
- รองรับ Desktop / Tablet / Mobile ผ่าน responsive overrides

ตรวจแล้ว:
- PHP lint ผ่านทุกไฟล์
- JavaScript syntax check ผ่านทุกไฟล์
- CSS brace balance ถูกต้อง
