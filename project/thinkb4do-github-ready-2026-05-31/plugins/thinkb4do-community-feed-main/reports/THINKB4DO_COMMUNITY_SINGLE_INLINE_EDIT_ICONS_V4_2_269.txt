Thinkb4do Community Feed Main v4.2.269

หัวข้อ: Single Post / หน้าแสดงความคิดเห็น - ไอคอนแก้ไข/ลบใหม่ + Inline Post Edit

สิ่งที่แก้:
1) เปลี่ยนปุ่มแก้ไข/ลบของโพสต์หน้าแสดงความคิดเห็นเป็น SVG แบบฝังในไฟล์ ไม่พึ่ง icon font ภายนอก จึงไม่เกิดช่องว่าง/ไอคอนไม่ขึ้น
2) ปุ่มแก้ไขโพสต์ไม่เปิด composer modal เดิมแล้ว เปลี่ยนเป็นกล่องแก้ไข inline คล้ายระบบแก้ไขความคิดเห็นด้านล่าง
3) กล่องแก้ไขโพสต์มีช่องหัวข้อ, รายละเอียด, ปุ่มบันทึก, ปุ่มยกเลิก และสถานะกำลังบันทึก/สำเร็จ/ผิดพลาด
4) เมื่อบันทึกสำเร็จ ระบบอัปเดตหัวข้อและเนื้อหาบนหน้าเดิมทันทีโดยไม่ต้องรีเฟรช
5) ปุ่มลบโพสต์ยังใช้ระบบ AJAX เดิม แต่เปลี่ยนไอคอนเป็น SVG ใหม่ให้เห็นชัด
6) ปรับ CSS ไอคอนแก้ไข/ลบความคิดเห็นให้เป็นเส้น SVG ชัดเจน ไม่ดูเป็นก้อนดำ

ตรวจสอบ:
- PHP syntax: ผ่าน
- Inline JavaScript syntax: ผ่าน
- ZIP package: พร้อมติดตั้งเป็นปลั๊กอิน WordPress

สถานะ:
ใช้งานได้แล้วสำหรับหน้า single/community-post และยังคงหน้าฟีดหลัก / หน้า members removal / feed width จากเวอร์ชันก่อนหน้าไว้
