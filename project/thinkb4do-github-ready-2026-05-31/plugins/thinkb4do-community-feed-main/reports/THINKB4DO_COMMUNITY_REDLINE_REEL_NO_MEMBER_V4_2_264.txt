Thinkb4do Community Feed Main v4.2.264

สรุปการแก้ไขตามโจทย์ล่าสุด:
1) ปรับขนาด Feed Main ให้พอดีตามแนวขีดแดง
   - ล็อกความกว้างแกนกลางไว้ที่ 720px บน Desktop
   - ไม่ให้การ์ด / composer / reel / feed list ล้นออกด้านข้าง
   - มือถือกลับเป็น 100% ตามขนาดหน้าจอ

2) เอาหน้าสมาชิกออกจาก Feed Main
   - Feed Main ยังไม่โหลด/ไม่เป็นเจ้าของหน้าสมาชิก
   - เพิ่มตัวซ่อนลิงก์เมนู “สมาชิก / member / members / profile / account” บนหน้าชุมชน เพื่อไม่ให้เมนูสมาชิกจาก sidebar/header เก่ามาโผล่ในหน้าฟีดหลัก
   - ไม่ไปยุ่งกับลิงก์ผู้เขียนในโพสต์หรือใน Reel

3) เพิ่มปุ่ม Next ซ้าย/ขวา ให้ Reel
   - เพิ่มปุ่มเลื่อนซ้าย/ขวาในราง Reel หน้า Feed
   - เพิ่ม JS ควบคุม Reel Viewer เองโดยไม่พึ่ง legacy controller เดิม
   - ปุ่ม ดูทั้งหมด / การ์ด Reel / ปุ่มก่อนหน้า / ถัดไป / ปิด Reel ทำงานในตัวหลัก

4) ลดระบบซ้อน
   - ตัด Reel controls ออกจาก legacy lazy trigger ใน community-runtime.js
   - ให้ community.js เป็นตัวคุม Reel หลักเพียงชุดเดียว

สถานะ QC:
- PHP syntax: ต้องตรวจด้วย php -l หลังแพ็ก
- JS syntax: ต้องตรวจด้วย node --check หลังแพ็ก
- สถานะใช้งาน: พร้อมติดตั้งทับ v4.2.263
