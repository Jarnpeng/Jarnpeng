AiRA Studio v7.5.7.7 — Post-Slide Insight Numbers

เป้าหมาย
- ปรับ Prompt processor ให้ไม่แสดงเงื่อนไข/ตัวอย่าง/รับรู้ความหมายระหว่างกำลังประมวลผล
- ให้ชุดหมายเลขรับรู้ความหมายขึ้นหลังคำตอบจริงสไลด์อักษรจบแล้วเท่านั้น

สิ่งที่แก้
1) ระหว่าง Prompt processor
   - แสดงเฉพาะสถานะอ่าน/ประมวลผลและจุดสามจุดนุ่ม ๆ
   - ไม่ขึ้นหมายเลข ความหมาย ตัวอย่าง เงื่อนไข ใช้ต่อ ก่อนคำตอบจริง

2) หลังคำตอบสไลด์จบ
   - ค่อยเพิ่มแถวตัวเลือก/รับรู้ความหมายใต้คำตอบ
   - หมายเลขยังต่อจากตัวเลือกเดิม
   - กดแล้วใส่เฉพาะตัวเลขเข้า Composer และซ่อน prompt ยาวไว้เบื้องหลัง

3) ความลื่นไหล
   - ลดความรกระหว่าง processor
   - ทำให้ผู้ใช้เห็นลำดับ: Processor → Slide Answer → Insight Numbers
