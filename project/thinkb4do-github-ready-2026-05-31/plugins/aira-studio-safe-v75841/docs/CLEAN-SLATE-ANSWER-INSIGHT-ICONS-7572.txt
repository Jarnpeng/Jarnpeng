AiRA Studio v7.5.7.2 — Answer Insight Icon Engine

เพิ่มไอคอนใต้คำตอบผู้ตอบเมื่อระบบพบสัญญาณว่าในคำตอบมีเงื่อนไข ตัวอย่าง ความหมาย ศัพท์ คำสั่ง หรือจุดที่ผู้ใช้ควรรู้ความหมายต่อ

สิ่งที่เพิ่ม
- แถวไอคอน รับรู้ความหมาย ใต้คำตอบผู้ตอบ
- ปุ่ม ความหมาย / ตัวอย่าง / เงื่อนไข / ใช้ต่อ
- ทุกปุ่มใส่ aria-label, data-insight-meaning, data-insight-benefit และ prompt ต่อเนื่องเข้า Composer
- ไม่เริ่มบริบทใหม่ ใช้คำตอบก่อนหน้าเป็นบริบทหลัก
- รองรับมือถือด้วยปุ่มขนาดกดง่ายและไม่ซ้อน message tools

ประโยชน์ผู้ใช้
- ถ้าคำตอบมีเงื่อนไขหรือยกตัวอย่าง ผู้ใช้กดถามความหมายต่อได้ทันที
- ลดการพิมพ์ซ้ำ
- ทำให้ AiRA ตอบต่อเนื่องลึกขึ้น แต่ยังปลอดภัย ไม่อ้างว่าอ่านใจจริง
