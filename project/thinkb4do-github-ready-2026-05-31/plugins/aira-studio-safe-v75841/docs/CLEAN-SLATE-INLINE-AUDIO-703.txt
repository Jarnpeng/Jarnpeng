AiRA Studio v7.0.3 — Clean Slate Inline Audio Player

เป้าหมาย:
- เมื่อกดปุ่มเล่นเสียงของข้อความผู้ตอบ ให้เครื่องเล่นเสียงโผล่ใต้ข้อความผู้ตอบนั้นทันที
- เครื่องเล่นเสียงต้องดัน layout ลง ไม่ใช่ overlay, popup, fixed หรือ body audio ที่ซ้อนกับหน้า
- ยังคง Clean Slate: CSS หลัก 1 ไฟล์ + JS หลัก 1 ไฟล์

สิ่งที่เพิ่ม:
- Inline message audio player ในกล่องข้อความผู้ตอบ
- ปุ่มหยุดเสียงและปิด player เฉพาะข้อความนั้น
- หยุด player อื่นเมื่อเปิด player ใหม่ เพื่อลดเสียงซ้อน
- Fallback ไปใช้ browser speech synthesis หาก API TTS ไม่คืนไฟล์เสียง

จุดทดสอบ:
1. กดปุ่มเล่นเสียงใต้ข้อความผู้ตอบ
2. Player ต้องโผล่ใต้ข้อความนั้นและดันพื้นที่ลง
3. ไม่ควรไปแสดงเฉพาะ composer audio dock
4. ปุ่มหยุดและปิด player ใช้งานได้
5. UI ไม่ซ้อนและ chat scroll ไม่กระตุก
