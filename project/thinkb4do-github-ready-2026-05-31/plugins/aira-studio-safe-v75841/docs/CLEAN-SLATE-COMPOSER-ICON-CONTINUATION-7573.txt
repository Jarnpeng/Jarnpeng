AiRA Studio v7.5.7.3 — Composer Icon Continuation

เพิ่มระบบเมื่อกดปุ่มใต้คำตอบ เช่น Answer / ความหมาย / ตัวอย่าง / เงื่อนไข / ใช้ต่อ / ตัวเลือกข้อ 1,2,3 แล้ว Composer จะแสดงเป็นชิปไอคอนเล็กแทนการใส่ prompt ยาวในช่องพิมพ์

สิ่งที่เพิ่ม
- Hidden continuation prompt เก็บบริบทคำตอบเดิมแบบซ่อน
- Composer chip แสดงไอคอน + label สั้น เช่น Answer, ข้อ 1, อธิบายความหมาย
- ผู้ใช้พิมพ์ข้อความต่อท้ายได้ทันทีโดยช่องไม่รก
- ตอนส่ง ระบบรวม hidden prompt + ข้อความที่ผู้ใช้พิมพ์เพิ่ม
- ปุ่มส่งไม่ disabled แม้ช่องพิมพ์ว่างแต่มี hidden continuation prompt
- มีปุ่ม x ล้างบริบทคุยต่อใน Composer

ประโยชน์ผู้ใช้
- ลดข้อความยาวรกใน composer
- เห็นชัดว่ากำลังคุยต่อจากคำตอบ/ปุ่มไหน
- ยังพิมพ์รายละเอียดเพิ่มได้เหมือน GPT
- ไม่เสียบริบทเดิมและไม่เริ่มใหม่โดยไม่จำเป็น
