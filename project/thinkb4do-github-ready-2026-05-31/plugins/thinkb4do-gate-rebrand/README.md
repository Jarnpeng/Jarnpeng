# Thinkb4do Think Control

ระบบทางเข้า แบรนด์กลาง โลโก้กลาง ฟอนต์มาตรฐาน และพื้นที่สมาชิกของ Thinkb4do แบบแบรนด์ของตัวเอง

## ความสามารถหลัก

- สร้าง URL ทางเข้าใหม่ เช่น `/think-gate/`
- สร้างหน้าสมัครสมาชิก เช่น `/member-register/`
- สร้างหน้าต้อนรับแบบพิเศษเฉพาะผู้มีสิทธิ์ เช่น `/think-control/`
- ซ่อนทางเข้าเดิมสำหรับคนทั่วไป
- ดัก URL ที่มักถูกใช้ก่อกวน เช่น `/admin/`, `/login/`, `/backend/`, `/panel/`, `/phpmyadmin/`, `/.env/` แล้วส่งไปหน้า Login หรือสมัครสมาชิก
- ส่งคนที่ยังไม่เข้าสู่ระบบไปหน้า Think Control ใหม่
- จำกัดจำนวนครั้งเมื่อกรอกรหัสผิด
- บล็อกการสแกนชื่อผู้ดูแลแบบพื้นฐาน
- ปิดช่องทางเชื่อมต่อเก่าบางส่วนได้จากหน้า Settings
- รองรับ Shortcode สำหรับหน้า Login / Register / Locked Content
- เอาชุดลิงก์ทำงานต่อออกจากหน้าเข้าสู่ระบบ
- ผู้มีสิทธิ์ที่ล็อกอินอยู่แล้วจะถูกส่งไปหน้าต้อนรับผู้มีสิทธิ์ทันที
- เพิ่มปุ่มสำรองไปหน้าต้อนรับและกลับ Dashboard หลัก เมื่อมีการแสดงสถานะล็อกอินสำเร็จ
- เพิ่มลิงก์ทำงานต่อสำหรับผู้มีสิทธิ์ในหน้า Settings, Dashboard หลัก และหน้าต้อนรับ
- แก้หน้าขอยืนยันออกจากระบบเดิมให้ถูกแทนที่ด้วยหน้าดีไซน์ Thinkb4do แม้ลิงก์ยืนยันหมดอายุ
- แยกระดับสิทธิ์: ผู้ดูแลควบคุมใหญ่สุด / แอดมิน / สมาชิกทั่วไป
- ตั้งค่าช่องทางปลายทางกู้คืนและเลือกบัญชีกู้คืนจากชื่อ โดยไม่เปิดเผยข้อมูลบนหน้า Login
- สมาชิกทั่วไปที่ไม่มีสิทธิ์เข้าหลังบ้านจะถูกส่งกลับหน้าเว็บปกติ
- ผู้มีสิทธิ์ล็อกอินสำเร็จแล้วเข้าหน้าต้อนรับพิเศษทันที พร้อมปุ่มกลับ Dashboard หลัก
- ดีไซน์ responsive สำหรับมือถือ แท็บเล็ต และเดสก์ท็อป
- เพิ่ม Brand Core สำหรับเลือกโลโก้จาก Media Library ครั้งเดียว แล้วใช้ร่วมกันทุกหน้า
- เพิ่มรูปอัตลักษณ์ / Info Illustration สำหรับแทนภาพคนหรือภาพสามคน
- ปรับฟอนต์ทุกระบบให้อ่านง่ายแบบมาตรฐานสากล: Noto Sans Thai / Kanit + Inter / Roboto + System UI
- เพิ่มสถานะจริงใจ “อยู่ระหว่างเตรียมข้อมูลจดทะเบียน” และไม่ใช้โลโก้ DBD/ราชการก่อนอนุมัติจริง
- เพิ่ม Shortcode สำหรับโลโก้ รูปอัตลักษณ์ และสถานะแบรนด์

## ทางเข้าหลัก

ค่าเริ่มต้น:

```text
/think-gate/
/member-register/
/think-control/
```


## ระดับสิทธิ์

```text
ผู้ดูแลควบคุมใหญ่สุด = คุมทุกส่วนของระบบและตั้งค่า Think Control ได้
แอดมิน = เข้าหลังบ้านและทำงานต่อได้ตามสิทธิ์ที่ระบบกำหนด
สมาชิกทั่วไป = ไม่มีสิทธิ์เข้าหลังบ้าน ระบบจะส่งกลับหน้าเว็บปกติ
```

## วิธีใช้งาน

1. อัปโหลดแพ็กนี้ในหน้าจัดการระบบ
2. เปิดใช้งาน Thinkb4do Think Control
3. เข้าเมนู Settings > Think Control
4. ตรวจ URL ทางเข้าใหม่
5. Bookmark URL ใหม่ทันที
6. เข้าเมนู Brand Core / โลโก้กลาง แล้วเลือกโลโก้หลักจาก Media Library
7. เลือกรูปอัตลักษณ์ / Info Illustration ถ้ามี
8. ตรวจข้อความสถานะจดทะเบียนให้ตรงกับสถานะจริง
9. ทดสอบ Login / Register / Locked Content
10. ทดสอบ URL ก่อกวน เช่น `/admin/` หรือ `/panel/` ว่าถูกส่งไปหน้า Login หรือสมัครสมาชิกตามค่าที่ตั้งไว้
11. เปิด “จำสิทธิ์อัตโนมัติ” เพื่อให้ระบบจำบัญชีผู้ดูแลควบคุมและแอดมินเองหลัง Login สำเร็จ
12. ตั้งค่า “ปลายทางสมาชิกทั่วไป” เป็นหน้าเว็บปกติ
13. ตั้งค่า “ช่องทางปลายทางกู้คืน” และเลือกบัญชีกู้คืนจากชื่อ
14. เพิ่มลิงก์ทำงานต่อในช่อง “ลิงก์ทำงานต่อเพิ่มเติม” ด้วยรูปแบบ `ชื่อปุ่ม|URL`

## วิธีแก้กรณีลืม URL

1. เข้า File Manager หรือ FTP
2. ไปที่โฟลเดอร์ส่วนเสริมของระบบ
3. เปลี่ยนชื่อโฟลเดอร์ `thinkb4do-gate` เป็น `thinkb4do-gate-off`
4. เข้าระบบด้วยทางเดิมชั่วคราว
5. เปลี่ยนชื่อโฟลเดอร์กลับเมื่อต้องการเปิดใช้งานใหม่

## หมายเหตุด้านความปลอดภัย

ระบบนี้ช่วยลดการเดา URL และลดบอทก่อกวน แต่ควรเสริม 2FA, จำกัด IP, Cloudflare และรหัสผ่านที่แข็งแรงสำหรับบัญชีผู้ดูแล

## สถานะ

- ระบบพร้อมติดตั้งทดสอบ
- ไม่แก้ไฟล์หลักของระบบ
- เหมาะสำหรับใช้เป็น Think Control หน้าแรกของหลังบ้านและพื้นที่สมาชิก
- เพิ่มตัวดัก URL ก่อกวนแล้ว
- เพิ่ม Admin Work Links แล้ว
- เพิ่ม Role Access Guard + Auto Remember Access แล้ว
- เพิ่ม Recovery Mail แล้ว
- เพิ่มหน้าต้อนรับแบบพิเศษเฉพาะผู้มีสิทธิ์แล้ว
- สมาชิกทั่วไปกลับหน้าเว็บปกติแล้ว

- เพิ่มตัวค้นหาชื่อบัญชีเพื่อเลือกสิทธิ์ โดยระบบเก็บรหัสภายในให้อัตโนมัติ
