Thinkb4do Discovery 1.4.2

สถานะ: พร้อมติดตั้งแทนเวอร์ชันเดิม

ปรับในเวอร์ชันนี้:
- ทำพื้นหลังใหม่ให้เนียนขึ้นและไม่มีขอบแสงแข็งด้านซ้าย/ขวา
- คุมพื้นหลังให้เป็น soft gradient ต่อเนื่อง โทนเขียว/ขาว/ส้ม/ดำของ Thinkb4do
- หน้า Public แสดงข้อความหลักเฉพาะ “กำลังพัฒนาเว็บ” และ Thinkb4do.com
- ไม่แสดงคำอธิบายไอเดีย รายละเอียดระบบ หรือข้อมูลหลังบ้านบนหน้า Public
- รองรับมือถือ แท็บเล็ต เดสก์ท็อป และใช้ browser scrollbar ปกติ
- ลดเส้น/วง/ขอบตกแต่งที่ทำให้พื้นหลังดูไม่เรียบ

วิธีติดตั้ง:
1. ไปที่ WordPress Admin > Plugins > Add New > Upload Plugin
2. อัปโหลดไฟล์ ZIP นี้
3. กด Replace current with uploaded หากระบบถาม
4. ล้าง cache เว็บ/เบราว์เซอร์ แล้วเปิดหน้า Discovery หรือหน้าแรกอีกครั้ง
