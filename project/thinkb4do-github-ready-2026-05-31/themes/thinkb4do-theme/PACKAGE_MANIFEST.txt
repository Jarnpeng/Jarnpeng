Thinkb4do Theme Core v2.0.0
===========================
Root folder: thinkb4do-theme
Purpose: Core visual theme only. Live editing, Gutenberg frontend tools, autosave, media/color designer and component editor are separated into the plugin "Thinkb4do Live Studio".

Core theme includes:
- WordPress templates: header.php, footer.php, front-page.php, page.php, single.php, archive.php, 404.php
- Theme settings/customizer and Thinkb4do visual system
- Header/mobile/dropdown/popup positioning fixes
- Main frontend scripts: js/compat.js, js/main.js, js/mobile-menu-anchor-fix.js
- Gutenberg is not disabled by the theme

Install order:
1) Install/activate this theme
2) Install/activate thinkb4do-live-studio-v2.0.0.zip for live edit tools
