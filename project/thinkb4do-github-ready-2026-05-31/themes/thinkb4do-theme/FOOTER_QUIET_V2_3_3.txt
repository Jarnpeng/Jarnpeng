THINKB4DO THEME CORE v2.3.3 — FOOTER QUIET

เป้าหมาย:
- ปรับ footer ให้เรียบ ไม่โดดเด่นเกินเนื้อหาหลัก
- คงลิงก์สำคัญไว้
- ลดสีเข้ม/สีจม/เงาหนัก
- รองรับมือถือ แท็บเล็ต เดสก์ท็อป และ safe area

สิ่งที่ปรับ:
1) เปลี่ยน footer จากพื้นเข้มเด่นมาก เป็นพื้นอ่อน #f7faf8 พร้อมเส้นแบ่งบาง
2) ลดขนาดตัวอักษร footer และลดน้ำหนัก heading
3) ลดเงา ปุ่ม และ social button ให้ไม่แย่งสายตา
4) เอา social placeholder ที่เป็นลิงก์ # ออก ถ้าไม่ได้ตั้งค่าลิงก์จริง
5) ปรับ newsletter เป็นฟอร์มเรียบ สีขาว ขอบบาง
6) ปรับ footer bottom ให้บางและอ่านง่าย
7) เพิ่ม responsive footer: 4 columns > 2 columns > 1 column
